# Support

Quartz is maintained as an independent open source project under Apache License 2.0.

- Use the bug report form for reproducible defects.
- Use the feature request form for scoped product proposals.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities.
- Check [README.md](README.md), [ROADMAP.md](ROADMAP.md), and [docs/PROJECT_AUDIT.md](docs/PROJECT_AUDIT.md) before opening a new issue.

Please include the Quartz version, macOS version, Apple Silicon model, reproduction steps, expected behavior, actual behavior, and relevant logs. Do not attach private note content unless it is essential and has been sanitized.
